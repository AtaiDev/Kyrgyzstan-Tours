# Kyrgyzstan Tours

Tourism platform for discovering destinations, booking excursions, and finding local guides in Kyrgyzstan.

## Tech Stack

- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Create React App](https://create-react-app.dev/) (`react-scripts` 5)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18 or newer
- npm (comes with Node.js)

### Installation

```bash
git clone https://github.com/AtaiDev/Kyrgyzstan-Tours.git
cd Kyrgyzstan-Tours
npm install
```

### Running locally

```bash
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000) and reloads automatically when you edit files.

## Available Scripts

| Command         | Description                                              |
| --------------- | -------------------------------------------------------- |
| `npm start`     | Runs the app in development mode                         |
| `npm test`      | Launches the test runner in interactive watch mode       |
| `npm run build` | Builds an optimized production bundle into `build/`      |
| `npm run eject` | Ejects from Create React App (one-way operation)         |
